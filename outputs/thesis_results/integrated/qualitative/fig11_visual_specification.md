# Figure 11 visual specification

Overall layout: four qualitative case rows by three model columns.

Shared columns:
- Centralized
- IID FedAvg
- Non-IID FedAvg

Each row contains:
- one row-level qualitative category;
- the shared true label once;
- one Grad-CAM overlay per model;
- concise prediction and confidence text per model.

The main figure intentionally omits image identifiers, internal experiment paths, and repeated model headings. Those details remain in the corrected source CSV and original-composite provenance file.
